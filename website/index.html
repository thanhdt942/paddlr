Open-source Agent Skills that bring specs, plans, test-driven development, debugging, code review, and release discipline to the coding agent you already use.

Get started View on GitHub

What is Paddlr?

Paddlr is not a coding agent. It is a plugin for the agents you already run — Claude Code, Codex, OpenCode, and Google Antigravity — that teaches them a consistent engineering workflow: understand the repository, plan proportionally to risk, implement in small slices, and verify with real command output before reporting done.

Coding agents are fast, but they often edit before reading the codebase, skip tests, claim success without evidence, and forget decisions between sessions. Paddlr turns proven practices into skills the agent follows, and keeps specs, plans, and decisions in docs/paddlr/ so context survives the session.

What you get

feature-development
Runs a feature end to end, from intake to verified completion.
writing-specs
Turns ideas into reviewable specs in docs/paddlr/specs/.
writing-plans
Breaks specs into small, contract-first plans in docs/paddlr/plans/.
test-driven-development
No production code without a failing test first.
sre-debugging
Evidence and hypotheses before any fix.
code-review
Independent, read-only review against the spec.
release-management
Versioning and release conventions recorded in RELEASE.md.
skill-creator
Design, verify, and package your own agent skills.

Also included: shared operating rules (AGENTS.md) and a session-start hook that loads them automatically. Useful if you rely on AI agents for real work in real repositories and want output you can review.

Install Paddlr

Choose your coding agent, then run each command in order.

Usage

Once installed, just describe the task. Your agent picks the matching skill and leaves reviewable artifacts in your repository.

Plan a feature before writing code

Prompt
Draft feature specifications and implementation plan with Paddlr: add CSV export to the reports page

The agent inspects the repository, asks about real ambiguities, then writes a spec to docs/paddlr/specs/ and a step-by-step plan to docs/paddlr/plans/ for your approval.

Implement test-first

Prompt
Run TDD to implement the CSV export (RED -> GREEN -> REFACTOR)

The agent writes a failing test, watches it fail, then adds the minimal code to make it pass — and shows you the test output at each step.

Debug with evidence

Prompt
Systematically investigate and debug a failure with sre-debugging: the export job times out

The agent reproduces the problem, gathers evidence, and tests hypotheses before proposing a fix.

In Claude Code, the skills are also available as slash commands, such as /paddlr:writing-specs. Full reference in the documentation.
