What is Paddlr?

Paddlr is not a coding agent. It is an open-source plugin of 57 Agent Skills for Claude Code, Codex, OpenCode, Google Antigravity, and Cursor. It keeps your agent reading the codebase first, planning by risk, saving context in docs/paddlr/, and verifying with real command output.

Persistent project memory

Stores specs, plans, and ADRs in docs/paddlr/ so context survives across sessions.

Reversibility-first autonomy

Small fixes and branch work run directly. High-risk changes always pause for approval.

Evidence-based verification

Runs real tests, lint, or runtime checks before reporting done.

Ships with shared operating rules in AGENTS.md and a session-start hook that loads them automatically.

Install Paddlr

Choose your coding agent, then run each command in order.

After installing, run /setup-paddlr to initialize docs/paddlr/ or create a .paddlr.json override. Run /paddlr-help for read-only routing without executing tasks.

Paddlr mode

Invoke /paddlr-mode as a single entry point for disciplined sessions. The skill stays lazy-loaded via disable-model-invocation: true, so it adds zero context overhead until you call it.

paddlr-mode bundles 22 playbooks (feature, bug fix, refactoring, investigation, opening a PR, and more) alongside 26 engineering principles loaded on demand when a trigger matches.

How a session runs

  1. Restate the goal

    The agent restates your goal and the smallest change that meets it before touching code.

  2. Classify risk and pick a playbook

    Assigns Level 1, 2, or 3 based on reversibility and opens the matching playbook.

  3. Track state in plan and native checklist

    Mirrors active steps from docs/paddlr/plans/ into your host's native checklist via ui.todo (TodoWrite, update_steps, update_plan, todowrite, or chat fallback).

  4. Build, verify, and open a PR

    Implements in verifiable slices, checks the real artifact, runs sync-docs and code-review, and opens a ready-for-review PR.

Paddlr runs in a single thread using only 5 basic tools (read, write, patch, shell, search). When your host supports subagents, Paddlr can delegate isolated slices while the main agent keeps canonical plan ownership.

Core skills

paddlr-mode
Single entry point with 22 playbooks and 26 engineering principles loaded on demand.
setup-paddlr / paddlr-help
Initialize docs/paddlr/ or .paddlr.json, and route questions read-only without running tasks.
feature-development
Runs a 5-phase spec-driven feature lifecycle from intake to verified completion.
writing-specs / writing-plans
Turns ideas into reviewable specs in docs/paddlr/specs/ and contract-first plans in docs/paddlr/plans/.
writing-decisions / sync-docs
Writes immutable ADRs in decisions/ indexed in DECISIONS.md, and checks docs for drift before a PR.
test-driven-development
Enforces strict RED, GREEN, REFACTOR execution with no production code before a failing test.
sre-debugging
Reproduces failures, gathers evidence, and tests hypotheses before proposing a fix.
code-review / interrogate
Runs independent read-only spec alignment review and adversarial red-teaming.
no-comments / unslop / correct
Audits stale comments and workarounds, cuts AI prose filler, and turns repeated mistakes into structural checks.
release-management / skill-creator
Records release rules in RELEASE.md and authors new validated Agent Skills.

Usage

Once installed, describe the task or invoke a slash command. Your agent selects the matching skill and leaves reviewable artifacts in your repository.

Start a disciplined session with /paddlr-mode

Prompt 
/paddlr-mode Add CSV export to the reports page

/paddlr-mode restates the goal, classifies risk, writes a spec and plan to docs/paddlr/plans/, verifies on the real artifact, and prepares a clean PR.

Plan a feature before writing code

Prompt 
Draft feature specifications and implementation plan with Paddlr: add CSV export to the reports page

The agent inspects the repository, asks about real ambiguities, then writes a spec to docs/paddlr/specs/ and a step-by-step plan to docs/paddlr/plans/.

Implement test-first

Prompt 
Run TDD to implement the CSV export (RED -> GREEN -> REFACTOR)

The agent writes a failing test, watches it fail, adds the minimal code to make it pass, and shows real test output at each step.

Debug with evidence

Prompt 
Systematically investigate and debug a failure with sre-debugging: the export job times out

The agent reproduces the failure, gathers evidence, and tests hypotheses before proposing a fix.

In Claude Code, skills are also available as slash commands such as /paddlr:writing-specs and /paddlr:paddlr-mode. Read the full User Guide.
