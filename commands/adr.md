# /pdl:adr — Writing Decisions (ADR)

**Task:** $ARGUMENTS

Apply the **Writing Decisions** skill to record or supersede an immutable Architectural Decision Record in `docs/paddlr/decisions/` (or the path configured in `.paddlr.json`).

1. Read the skill entrypoint ([writing-decisions/SKILL.md](../skills/writing-decisions/SKILL.md)).
2. Inspect `DECISIONS.md` and `decisions/` to assign the next sequence ID or locate the ADR being superseded.
3. Author the ADR file, update `DECISIONS.md`, and present it for review when `Proposed`.
