# Feature Specification: Release v3.3.1 — Fix Canonical Project Memory Path (docs/hsiw)

- **Date:** 2026-11-19
- **Author:** Antigravity / Release Management
- **Status:** Reviewable / Pending Confirmation
- **Release Target:** `v3.3.1`
- **Release Type:** Patch (SemVer 2.0.0)

## 1. Objective & Background

Following the release of `v3.3.0`, legacy `.hsiw/` path references remained in `rules/AGENTS.md`, `rules/CLAUDE.md`, `hooks/session-start.py`, `index.js`, `README.md`, commands, and plugin manifests. This caused agents to inadvertently create project memory artifacts under `.hsiw/` instead of the canonical `docs/hsiw/` standard established in `v3.0.0`.

This patch release:
1. Bumps all platform manifests to `3.3.1`.
2. Persists the fix in `CHANGELOG.md` under `[3.3.1] - 2026-11-19`.
3. Updates `RELEASE.md` current version to `3.3.1`.
4. Runs full skills validation and unit test suites.
5. Executes release commit and git tag `v3.3.1`.
