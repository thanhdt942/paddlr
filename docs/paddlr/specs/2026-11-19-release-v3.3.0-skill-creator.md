# Feature Specification: Release v3.3.0 — Add skill-creator Skill

- **Date:** 2026-11-19
- **Author:** Antigravity / Release Management
- **Status:** Reviewable / Pending Confirmation
- **Release Target:** `v3.3.0`
- **Release Type:** Minor (SemVer 2.0.0)

## 1. Objective & Background

HolyShitItWorks (HSIW) provides systematic software engineering discipline, risk-based workflows, and reusable Agent Skills. To support users and developers in creating high-quality, reliable, portable Agent Skills that conform to open standards, a new skill `skills/skill-creator` has been introduced.

This release packages and validates `skill-creator`, updates all platform manifests (Antigravity, Claude Code, OpenAI Codex, OpenCode), updates command routers and lifecycle hooks, establishes `RELEASE.md` persistent configuration, updates documentation/changelog, and verifies all test suites.

## 2. In Scope & Out of Scope

### In Scope
1. **Skill Integration:**
   - Package `skills/skill-creator` (`SKILL.md`, `references/skill-anatomy.md`, `references/testing-guide.md`).
   - Create slash command `commands/skill-creator.md` (`/hsiw:skill-creator`).
2. **Platform Manifests Bump (3.2.0 -> 3.3.0):**
   - `plugin.json` (Antigravity)
   - `package.json` (OpenCode / npm)
   - `.claude-plugin/plugin.json` & `.claude-plugin/marketplace.json` (Claude Code)
   - `.codex-plugin/plugin.json` & `.agents/plugins/marketplace.json` (OpenAI Codex)
   - `.release-please-manifest.json`
   - `.opencode/INSTALL.md`
3. **SessionStart Hooks & Instructions:**
   - `hooks/session-start.py` (add `skills/skill-creator`)
   - `index.js` (add `skills/skill-creator`)
   - `rules/CLAUDE.md` (add `/hsiw:skill-creator`)
4. **Documentation & Changelog:**
   - `CHANGELOG.md` (document `v3.3.0` additions)
   - `README.md` (skills table, slash commands list, test badge)
5. **Release Management Persistence:**
   - Create `RELEASE.md` with confirmed project release policies.
6. **Verification:**
   - `tests/test_commands.py`: add `skill-creator` to `EXPECTED_COMMANDS`.
   - `tests/test_core_skills_architecture.py`: add `skill-creator` to `EXPECTED_SKILLS` and assert methodology retention.
   - `tests/test_workflow_scenarios.py`: add `skill-creator` to `REQUIRED_SKILLS`.
   - Run `python scripts/validate_skills.py --verbose` (must pass 8 skills).
   - Run `python -m unittest discover -s tests -v` (must pass all tests).

### Out of Scope
- Modifying other existing skills or core principles.
- Direct release branch edits (generated by workflow).
- Unapproved Git commit / tag push / remote publishing without explicit authorization.
